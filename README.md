# DeMOCKracy 🪳

> *A govt that can't tolerate a protest, can't tolerate democracy.*

A satirical Chrome Dino-style endless runner browser game rooted in the Oct 2026 India protests, the [Cockroach Janta Party (CJP)](https://en.wikipedia.org/wiki/Cockroach_Janta_Party) movement, and the crackdown on democratic dissent.

---

## 🎮 How to Play

| Action | Desktop | Mobile |
|--------|---------|--------|
| Jump | `Space` / `↑` | Tap top half |
| Duck | `↓` | Tap bottom half |
| Select character | `← →` | Tap character boxes |
| Start / Restart | `Space` / Click | Tap |
| Mute | `M` | — |

### Characters
- 🪳 **Cockroach** — CJP mascot. "Cockroaches never die."
- 🦖 **Dino** — Classic Chrome runner
- 📢 **Student** — Placard raised. "Save Democracy."
- 📷 **Journalist** — Camera in hand. "Press is not a crime."

### Obstacles
- 🚧 **Delhi Police Barricade** — The iconic metal frame. Jump it.
- 🪵 **Lathi (Baton)** — Jump the swinging baton.
- 💨 **Tear Gas Canister** — Rolling smoke. Jump it.
- 📋 **Section 163 Board** — Prohibits assembly of 5+. Jump the sign.
- 🚌 **Police Detention Bus** — Tall. Hard to clear.
- 🚁 **CCTV Drone** — Aerial surveillance. Duck under it.
- 💦 **Water Cannon Stream** — Aerial blast. Duck.

## 🛠 Run Locally

No build step needed. Pure HTML + JS.

```bash
cd demockracy
npx serve .
# Open http://localhost:3000
```

---

## 🚀 Deploy

### Vercel
```bash
npx vercel
```

### Netlify
Drag the `demockracy/` folder onto [netlify.com/drop](https://app.netlify.com/drop)

Or connect GitHub repo and Netlify auto-deploys on push.
